## 2. 支柱功能一：年龄分级知识

### 2.1 分级标准

| 年龄段 | 分级编码 | 认知特征 | 内容呈现策略 |
|--------|---------|---------|-------------|
| 6-9 岁 | AGE_06_09 | 具象思维为主，注意力 10-15 分钟 | 全图形化界面 > 80% 视觉元素，文字简洁每段 < 30 字，大量动画和音效反馈 |
| 10-12 岁 | AGE_10_12 | 逻辑思维萌芽，注意力 15-25 分钟 | 图文混合比例 1:1，引入简单逻辑题，故事化叙事 |
| 13-15 岁 | AGE_13_15 | 抽象思维发展，注意力 25-35 分钟 | 文字为主图文为辅，引入概念推导，复杂问题拆解 |
| 16-18 岁 | AGE_16_18 | 抽象思维成熟，注意力 35-50 分钟 | 纯文字 + 图表，学术化表达，跨学科综合题 |

### 2.2 用户故事

- **US-AGE-01**: 作为 8 岁学生，我打开平台后看到的是卡通风格的大按钮和大图标，文字很大，这样我能自己操作而不需要爸爸妈妈帮忙。
- **US-AGE-02**: 作为 15 岁学生，我看到的界面是信息密度较高的布局，可以直接看到知识目录和学习进度，这样我能高效安排学习。
- **US-AGE-03**: 作为家长，我希望系统能根据我孩子填写的年龄自动推荐合适的内容，同时我也能手动调整分级。
- **US-AGE-04**: 作为 6 岁学生的家长，我希望界面完全没有文字输入需求，所有操作通过点击大图标完成。

### 2.3 交互逻辑

1. 用户首次注册时填写出生日期 -> 系统自动计算年龄并分配默认分级
2. 在个人设置中可以手动调整年龄分级（向上/向下兼容一个相邻级别）
3. 每次进入学习模块时，系统根据当前分级筛选内容池
4. 分级决定：UI 布局方案、字体大小、内容深度、交互复杂度、反馈形式

## 3. 支柱功能二：难度自由选择

### 3.1 难度等级定义

| 难度 | 编码 | 定位 | 能力要求 | 正确率预期 |
|------|------|------|---------|-----------|
| 初级 | DIFF_EASY | 入门与基础 | 识记、理解 | > 80% |
| 中级 | DIFF_MEDIUM | 巩固与提升 | 应用、分析 | 60%-80% |
| 高级 | DIFF_HARD | 挑战与拓展 | 评价、创造 | 40%-60% |

### 3.2 用户故事

- **US-DIFF-01**: 作为 12 岁学生，我在学习"分数"这个知识点时觉得太简单，点击难度 + 按钮切换到中级，题目立刻变得更需要动脑筋了。
- **US-DIFF-02**: 作为 10 岁学生，高级太难了让我很沮丧，系统在连续答错 3 题后弹窗提示："是不是太难了？试试中级吧！"，我点击后自动降级。
- **US-DIFF-03**: 作为学习者，我希望在学习过程中可以随时切换难度，不需要退出当前学习单元。

### 3.3 自适应调整策略

- **降级触发条件**: 连续答错 >= 3 题；单题超时 >= 2x 该题标准用时
- **升级推荐条件**: 连续答对 >= 5 题且平均用时 <= 标准用时 80%
- **难度记忆**: 系统记住每个知识点最后完成时的难度等级
- **难度锁**: 高级难度需要完成中级内容进度 >= 60% 才能解锁（可手动覆盖）

## 4. 支柱功能三：知识类型自由选择

### 4.1 知识分类体系

#### 按学科分类

| 学科 | 编码 | 覆盖年龄段 | 说明 |
|------|------|-----------|------|
| 数学 | SUBJ_MATH | 全部 | 数与代数 / 图形几何 / 统计概率 / 逻辑推理 |
| 语文 | SUBJ_CHINESE | 全部 | 识字 / 阅读 / 写作 / 古诗文 / 语言表达 |
| 英语 | SUBJ_ENGLISH | 全部 | 词汇 / 语法 / 听说 / 读写 |
| 科学 | SUBJ_SCIENCE | 全部 | 物质科学 / 生命科学 / 地球宇宙 / 工程技术 |
| 历史 | SUBJ_HISTORY | 10-18 | 中国历史 / 世界历史 / 文明演进 |
| 编程 | SUBJ_CODE | 10-18 | 逻辑思维 / 图形化编程 / Python / 算法入门 |
| 艺术 | SUBJ_ART | 全部 | 美术欣赏 / 音乐基础 / 艺术史 |

#### 按学习形式分类

| 形式 | 编码 | 适用场景 | 典型时长 |
|------|------|---------|---------|
| 知识阅读 | TYPE_READ | 新概念学习、知识引入 | 5-15 min |
| 互动问答 | TYPE_QUIZ | 知识点巩固、自我检测 | 3-10 min |
| 游戏化练习 | TYPE_GAME | 技能训练、重复练习 | 5-20 min |
| 视频讲解 | TYPE_VIDEO | 复杂概念可视化（v0.2） | 3-15 min |
| 项目挑战 | TYPE_PROJECT | 综合应用、跨学科（v0.2） | 20-45 min |
| AI 对话 | TYPE_CHAT | 自由提问、深度探究（v0.2） | 不限 |

### 4.2 用户故事

- **US-TYPE-01**: 作为 14 岁学生，我想只做数学学科的练习题，筛选"数学 + 互动问答"，系统列出所有数学问答内容。
- **US-TYPE-02**: 作为 9 岁学生，我选了"科学 + 游戏化练习"，学习"植物生长"这个知识点时有拼图游戏、配对游戏和闯关三种形式可选。
- **US-TYPE-03**: 作为学习者，我想混合多种知识类型在一个学习会话中：先看一段知识阅读，再做互动问答巩固。

### 4.3 筛选器逻辑

```
知识筛选流程:
1. 选择年龄段          -> 内容池缩小至该年龄段
2. 选择学科           -> 进一步筛选
3. 选择学习形式        -> 再筛选
4. 选择难度           -> 最终确定内容列表
5. (可选) 搜索关键词    -> 精准匹配
```

筛选结果按"推荐"（基于历史行为和知识点关联度）和"全部"两个标签页展示。

## 5. AI 助手功能

### 5.1 能力矩阵

| 能力 | 触发方式 | 说明 |
|------|---------|------|
| 知识点讲解 | 点击"AI 解释"按钮 | 用当前年龄分级的语言风格解释概念 |
| AI 动态出题 | 用户选择课程 / 主题 / 难度 / 题型 / 数量 | 根据用户选择自动生成适龄题目、答案和解析 |
| 出题计划 | 开始练习前自动生成 | 将题目数量拆分为基础题、应用题、挑战题等结构 |
| 生成题目知识库 | 每次生成题目后自动保存 | 保存生成题目、Prompt、答案、解析、知识点标签、用户答题行为和题目指纹，随使用逐步沉淀为用户自己的题目知识库，供后续去重、复习、错题变式和个性化练习 |
| 错题变式 | 答错后或复习时触发 | 基于历史错题生成同知识点、同难度或稍低难度的变式题 |
| 错题解析 | 答错后自动触发 | 分析错误原因，给出针对性讲解 |
| 举一反三 | 学习完成后推荐 | 基于当前知识点推荐同类或进阶内容 |
| 自由问答 | 对话输入框（v0.2） | 不限范围的知识问答（限该学科领域） |
| 学习规划 | 每周首次登录（v0.2） | 根据学习进度生成下周学习计划建议 |
| 联网搜索 | v0.2 可选增强 | v0.1 不实现；仅在未来需要实时材料或权威外部资料时考虑 |
| 安全审计 | SafetyAuditAgent 对每道 AI 生成内容执行四维安全审查 | 安全审查在质量检查后自动触发，任一维度不达标则题目否决 |
| 质量趋势分析 | QualityReviewAgent 抽样深度审查+质量趋势分析 | 定期抽样审查，质量下降时提高抽样率，输出趋势报告 |
| Skill 自进化 | SummaryAgent 从会话数据中提炼可复用 Skill | 每次成功出题会话后自动评估是否创建或更新 Skill |
| 用户习惯学习 | SummaryAgent 持续建模用户能力、行为模式和偏好 | 每次学习会话结束后更新用户行为模型 |
| 实时错误日志 | ErrorLogger 实时捕获所有 Agent 执行错误 | 所有 Agent 步骤持续监控，四类错误分类路由 |

### 5.2 用户故事

- **US-AI-01**: 作为 8 岁学生，我问 AI"为什么天是蓝的？"，AI 用简单的比喻和图片风格回答，我听得懂。
- **US-AI-02**: 作为 17 岁学生，我问 AI"请用微积分的方法推导自由落体公式"，AI 给出完整的数学推导过程。
- **US-AI-03**: 我答错了一道题，AI 自动弹出解析，告诉我错在哪里，然后出一道同类型的题让我再试一次。
- **US-AI-04**: 作为 10 岁学生，我选择"数学 / 分数加法 / 中级 / 10 道题"，系统自动生成适合我的练习题，并在答完后给出解析。
- **US-AI-05**: 作为学习者，我不希望每次练习都遇到重复题，系统会参考之前生成过的题目，自动生成新的同类题。

### 5.3 AI 动态出题流程

v0.1 的核心 AI 能力是“课程选择 -> 动态出题 -> 答题记录 -> 生成题目知识库沉淀 -> 错题变式”。系统不依赖预置教材知识库，也不做联网搜索，但会把用户使用过程中生成和作答过的题目持续沉淀为可检索的用户题目知识库。

```
用户选择课程参数
  -> CourseIntentAgent 补齐结构化参数
  -> QuestionPlannerAgent 制定题目结构
  -> QuestionMemoryAgent 检索生成题目知识库中的历史生成题和错题
  -> QuestionGeneratorAgent 生成题目、答案、解析
  -> QualityCheckAgent 检查适龄性、答案正确性、难度、重复度
  -> 保存 GeneratedQuestion + Prompt + 质量检查日志到生成题目知识库
  -> SafetyAuditAgent: 四维安全审查（适龄性/准确性/公平性/隐私）
  -> FeedbackAggregator: 汇聚偏差信号，计算PID，生成ControlSignal
  -> ControlSignal 注入下一次生成循环
  -> 前端进入练习 / 答题流程
```

### 5.4 出题输入参数

| 参数 | 必填 | 说明 |
|------|------|------|
| age_group | 是 | 年龄分级，用于控制语言、难度和题目形式 |
| subject | 是 | 学科，如数学、语文、科学、英语 |
| course_topic | 是 | 课程主题，如分数加法、植物生长、古诗理解 |
| difficulty | 是 | 初级 / 中级 / 高级 |
| question_types | 是 | 选择题、填空题、判断题、应用题、简答题等 |
| question_count | 是 | 本次生成题目数量 |
| learning_goal | 否 | 本次练习目标，如巩固基础、错题复习、挑战提升 |
| avoid_recent_duplicates | 是 | 是否检索近期生成题并避免重复 |

### 5.5 职责边界

- AI 动态出题负责生成练习内容，不负责开放式联网搜索。
- 生成题目知识库保存“使用过程中生成过的题目和学习行为”，不是预置教材库，也不是外部资料库；它可以随着用户持续使用逐步形成个性化知识沉淀。
- 质量检查 Agent 负责判定题目是否可用，但最终学习记录仍由 LearningService 持久化。
- v0.1 不做外部网页检索；涉及实时资料、新闻材料、权威资料引用的能力进入 v0.2。

### 5.6 闭环控制参数

系统通过 PID 控制器实现出题质量的闭环调节，从产品视角理解三个分量：

| 参数 | 含义 | 产品行为 | 调节效果 |
|------|------|---------|---------|
| P（比例） | 当前批次通过率偏差的即时纠正力度 | 本批次质量突然下降时立即调整 | 快速响应突发质量问题，但可能过度调节 |
| I（积分） | 历史偏差趋势的系统性修正 | 持续偏低时逐步加大调整力度 | 消除长期累积偏差，防止质量持续下滑 |
| D（微分） | 质量变化速率的趋势干预 | 质量正在快速恶化时提前介入 | 平滑调节过程，避免震荡，预测趋势 |

**控制信号注入点**: ControlSignal 会影响 QuestionPlannerAgent（题型/难度分布）、QuestionMemoryAgent（去重阈值/检索范围）和 QuestionGeneratorAgent（生成策略参数），形成多维度联合调节。

### 5.7 自进化管理

**Skill 生命周期**:

```
创建 -> 验证 -> 部署 -> 评估 -> 更新/归档
  |        |        |        |        |
  SummaryAgent  小范围   注入    定期    效果达标则更新
  从会话中提炼   测试     出题    效果评估  不达标则归档
```

- **创建**: SummaryAgent 从成功会话中提炼可复用的策略，生成 Skill 文件草案。
- **验证**: 在小范围场景中测试 Skill 效果，确认质量提升后方可部署。
- **部署**: Skill 文件写入 Skill 存储目录，在后续出题会话中被自动引用。
- **评估**: 定期追踪 Skill 部署后的质量指标变化，判断是否有效。
- **更新/归档**: 效果达标的 Skill 更新版本；效果下降或不相关的 Skill 归档移除。

**记忆治理规则**:
- SessionMemory 默认 TTL 为 90 天，过期自动清理。
- 每日定时任务扫描即将过期的记忆，高价值记忆由 SummaryAgent 评估是否升级为长期 Skill。
- 用户可手动清除个人记忆数据。

**进化触发条件**:
- 连续 5 批次质量下降：自动触发 FeedbackAggregator 增强 PID 调节力度。
- 新错误模式出现：ErrorLogger 检测到新类型错误，触发 SafetyAuditAgent 重新审查相关策略。
- Skill 效果下降：部署后质量指标不升反降，触发 Skill 回滚至上一稳定版本。

## 6. 用户系统

### 6.1 账号体系

- 注册方式：手机号 / 邮箱 + 验证码
- 第三方登录：微信扫码

### 6.2 学习数据采集

| 数据类型 | 采集时机 | 用途 |
|---------|---------|------|
| 答题记录 | 每次答题 | 学情分析、难度调整 |
| 学习时长 | 每次会话 | 学习报告、专注度分析 |
| 知识点状态 | 每次完成 | 知识图谱、推荐引擎 |
| 交互行为 | 持续采集 | UI/UX 优化 |
| 搜索/提问记录 | 每次提问 | AI 模型优化、高频问题发现 |
