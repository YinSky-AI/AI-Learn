## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 适龄性优先 | UI 风格、信息密度、交互复杂度严格匹配年龄分级 |
| 直觉化操作 | 核心操作路径不超过 3 步，任何操作在 2 次点击内可达 |
| 即时反馈 | 每一次交互在 200ms 内给出视觉 / 听觉 / 动效反馈 |
| 低认知负荷 | 每个页面聚焦一个核心任务，不堆砌信息 |
| 包容性设计 | 大字体模式、色盲友好配色、键盘导航全覆盖 |

## 2. 视觉语言

### 2.0 强制风格基准

以下图片是 v0.1 页面产出的最高优先级风格基准，任何前端实现、设计调整、组件封装和验收截图都必须严格符合这些样例图体现的视觉风格：

| 样例图 | 对应页面 / 组件 | 风格要求 |
|--------|----------------|----------|
| `design_imgs/主页.png` | 首页 / Dashboard | 必须符合左侧学习应用导航、浅灰背景、白色圆角卡片、蓝色主色、柔和学科色块、轻阴影的信息面板风格 |
| `design_imgs/附页1.png` | Explore Knowledge / 知识探索页 | 必须符合简洁筛选栏、浅色标签、课程卡片网格、学科图标色块、低噪声留白的探索页风格 |
| `design_imgs/附页2.png` | Learning / 学习页 | 必须符合顶部课程栏、细进度条、白色内容卡、右侧 AI Assistant 面板、胶囊建议问题的学习页风格 |
| `design_imgs/附页3.png` | Profile / 个人中心页 | 必须符合双列资料/设置/统计卡片、连胜状态、彩色技能卡、徽章画廊的个人中心风格 |
| `design_imgs/ui组件设计参考.png` | 浮层组件 | 必须符合白色浮层、轻阴影、蓝色主操作、柔和选中态、清晰关闭/确认控件的组件风格 |

**硬性要求**:
- 最终页面必须以 `design_imgs/*.png` 为风格事实源，不要求像素级复刻，但不得自行改成营销页、暗色主题、渐变背景、拟物插画或其他风格。
- 样例图中的英文只用于参考布局、信息密度和组件层级；最终页面的导航、标题、按钮、卡片、弹窗、题目、提示、AI Assistant 内容和截图验收必须全部使用简体中文。
- 允许根据真实数据、产品功能和响应式需求调整布局细节，但整体视觉语言、信息密度、色彩、圆角、卡片质感、导航表达和组件状态必须与样例图一致。
- 整个页面的布局结构至少保持不变：左侧导航、顶部栏、主内容区、卡片区块、课程网格、学习页右侧 AI 面板、个人中心左右列、浮层组件位置关系不得被重新设计。
- Desktop 首要目标视口为 `1440x900`；该视口下截图必须与样例图在风格、视觉密度和产品气质上高度一致。
- 不得用大段说明文字解释功能；页面本身应像样例图一样是可直接使用的学习应用界面。

### 2.1 色彩系统

| 色名 | 色值 | 用途 |
|------|------|------|
| 品牌蓝 | #2563EB | 主色调、按钮、链接，代表信任与知识 |
| 活力橙 | #F59E0B | 高亮、成就、徽章，代表活力与激励 |
| 成功绿 | #10B981 | 正确反馈、进度完成 |
| 警示红 | #EF4444 | 错误反馈、警告 |
| 中性灰 | #6B7280 | 辅助文字、边框 |

**样例图色彩约束**:
- 页面背景统一使用极浅灰 `#F8FAFC` / `#F9FAFB`，主内容区域不使用纯白大背景。
- 侧边栏为白色，宽度约 `256px`，右侧有浅边界线 `#E5E7EB`。
- 品牌主色为蓝色 `#2563EB`，用于 Logo 方块、当前导航项、主按钮、进度条、链接和主要图标。
- 学科色块必须使用柔和浅色背景：数学浅蓝、科学浅黄、地理浅绿、语文浅粉、艺术浅紫、音乐浅红、编程浅靛蓝、英语浅黄。
- 卡片背景以白色为主，顶部插图区使用浅色填充；严禁使用重渐变、玻璃拟态和深色卡片。

**年龄分级色适应**:
- 6-9 岁：高饱和度、大色块、对比强烈
- 10-12 岁：中等饱和度、丰富配色
- 13-15 岁：低饱和度、冷静色调为主
- 16-18 岁：极简中性色、品牌色点缀

### 2.2 字体系统

| 年龄段 | 正文字号 | 标题字号 | 字体家族 |
|--------|---------|---------|---------|
| 6-9 岁 | 24-32px | 36-48px | 圆体 / 楷体（友好感） |
| 10-12 岁 | 18-24px | 28-36px | 无衬线（清晰感） |
| 13-15 岁 | 16-20px | 24-32px | 无衬线（效率感） |
| 16-18 岁 | 14-18px | 20-28px | 无衬线（成熟感） |

### 2.3 圆角与间距

| 元素 | 6-9 岁 | 10-12 岁 | 13-18 岁 |
|------|--------|---------|---------|
| 卡片圆角 | 20px | 16px | 12px |
| 按钮圆角 | 16px | 12px | 8px |
| 内容间距 | 32px | 24px | 16px |
| 触控目标 | >= 56px | >= 48px | >= 44px |

**样例图尺寸建议**:
- 侧边栏宽度：`256px`；Logo 区高度约 `64px`；底部用户块固定在侧边栏底部。
- 主内容左边距从侧边栏右边界开始，内容容器左右内边距约 `48px`。
- 顶部栏高度：`64px`；底部边框 `1px #E5E7EB`。
- 页面主体卡片圆角以 `12px-16px` 为主；大卡片 `16px`，按钮 `8px-12px`，胶囊标签 `8px-999px`。
- 卡片阴影必须轻：`0 8px 24px rgba(15, 23, 42, 0.04)` 或更弱，不得出现厚重投影。
- 课程卡片在 Desktop 下为 4 列网格，卡片宽度约 `236px`，高度约 `224px`，顶部色块高度约 `140px`。
- 尺寸可根据实际页面内容微调，但不得破坏样例图的清爽、轻量、卡片化学习工具风格。

## 3. 页面拓扑

```
+-- 首页 / 仪表盘 -------------------------+
|   +-- 年龄欢迎语 + 每日推荐              |
|   +-- 学习进度概览 (环状图)              |
|   +-- 快捷入口 (最近学习 / 推荐内容)     |
|   +-- 激励状态 (连胜 / 积分 / 成就)      |
+-- 知识探索页 ---------------------------+
|   +-- 筛选栏 (年龄/学科/形式/难度)       |
|   +-- 内容卡片网格                       |
|   |   +-- 卡片: 标题/进度/难度/形式图标  |
|   |   +-- 快速开始按钮                   |
|   +-- 搜索结果 (如有关键词)              |
+-- 学习页 (核心) -------------------------+
|   +-- 顶部: 返回/标题/进度条/难度切换    |
|   +-- 主体: 内容区域 (阅读/问答/游戏)    |
|   +-- 底部: 操作栏 (提交/提示/AI/下一题) |
|   +-- 侧边: AI 助手浮窗 (可折叠)         |
+-- 个人中心页 ---------------------------+
|   +-- 头像/昵称/年龄分级设置             |
|   +-- 学习设置 (默认难度/每日目标)       |
|   +-- 成就展示墙                         |
|   +-- 应用设置 (字体大小/音效/主题)      |
+-----------------------------------------+
```

### 3.1 样例页面布局细则

#### 首页 / `design_imgs/主页.png`
- 左侧固定导航，导航项顺序对应：首页、探索、学习、我的；当前项为浅蓝背景 + 蓝色图标文字。
- 顶部栏包含菜单图标、搜索框、通知图标、消息图标、圆形头像占位。
- 首屏上方是左右拼接欢迎横幅：左侧浅蓝目标区，右侧欢迎语、推荐课程、连胜 badge、主按钮。
- 中部左侧是 Weekly Progress 卡片，含环形进度和三条学科进度；右侧是 Continue Learning 两张横向课程卡。
- 下方是 My Achievements 三张统计卡，再往下是 Recommended For You 四列课程卡网格。

#### 知识探索页 / `design_imgs/附页1.png`
- 标题语义对应“知识探索”，位于顶部栏左侧，左侧导航保持固定。
- 筛选区域从上到下依次为 `Filters` 标题、四个筛选下拉按钮、Search 主按钮、已选标签、结果数量。
- 内容卡片必须是 4 列网格；每张卡片上半部分为学科浅色图标区，下半部分为学科点、标题、课程数、难度和时间信息。

#### 学习页 / `design_imgs/附页2.png`
- 顶部栏左侧为返回箭头 + 课程标题；右侧为难度选择胶囊、书签、头像。
- 主学习区宽度必须避开右侧 AI 面板，顶部显示“第 3 / 12 课”等中文进度文案和蓝色进度条。
- 内容卡片使用白色大圆角容器，标题左侧有蓝色竖线。
- 右侧 AI Assistant 面板固定宽度约 `328px`，从顶部栏下方延伸到底部，浅灰背景，底部固定输入框和圆形发送按钮。

#### 个人中心页 / `design_imgs/附页3.png`
- 左列为个人资料卡、Learning Settings、App Settings；右列为 Learning Streak、Subject Skills、Badge Gallery。
- Subject Skills 使用四张等宽彩色卡片，每张含圆形图标、百分比、学科名和等级。
- Badge Gallery 使用彩色徽章卡片网格；未解锁项为浅灰禁用态。

#### 浮层组件 / `design_imgs/ui组件设计参考.png`
- AI Assistant 浮窗宽约 `340px`，白色卡片，顶部状态为 Online，底部输入框 + 蓝色圆形发送按钮。
- Select Difficulty 弹窗宽约 `380px`，三档难度纵向排列；当前项浅蓝背景 + 蓝色描边，选中项右侧绿色对勾，锁定项显示锁图标。
- Subject 多选 Popover 宽约 `380px`，左侧选项区浅灰背景；复选框选中态为对应学科色，底部显示已选数量和 Apply 按钮。

## 4. 核心交互模式

### 4.1 难度切换

```
触发: 点击学习页顶部的难度指示器
  -> 弹出底部面板 (Bottom Sheet)
  -> 显示三个难度选项，当前级别标记选中
  -> 选择新难度
  -> 内容刷新 + 短促音效 + 过渡动画 (300ms)
  -> 显示新难度的第一个内容
```

### 4.2 知识筛选

```
触发: 进入"知识探索"页
  -> 顶部筛选栏: [年龄] [学科] [形式] [难度]
  -> 点击任一筛选项，弹出标签选择器
  -> 选择标签后即时刷新结果
  -> 支持多选 (与关系)
  -> 当前激活的筛选项高亮显示
```

### 4.3 AI 助手

```
触发: 点击学习页右下角 AI 图标
  -> AI 助手浮窗从右侧滑入 (320px 宽)
  -> 上部: 上下文感知的建议问题 (3 个)
  -> 中部: 对话历史气泡
  -> 底部: 输入框 + 发送按钮
  -> 用户输入后流式输出 (打字机效果)
  -> 支持数学公式渲染 (KaTeX)
```

## 5. 状态覆盖

| 状态 | 处理方式 |
|------|---------|
| 加载中 | Skeleton 骨架屏 (非 spinning 动画) |
| 空状态 | 插画 + 友好文案 + 行动按钮 |
| 错误状态 | 具体错误提示 + 重试按钮 |
| 网络离线 | Banner 提示 + 本地缓存内容可用提示 |
| 内容切换 | 平滑过渡动画 (300ms ease-out) |

---

## 6. 过渡动画

- 页面切换: Slide 滑动 (方向取决于导航层次)
- 内容刷新: Fade + Scale (卡片式)
- 反馈动效: 正确时绿色脉冲 / 错误时红色抖动
- 成就触发: 徽章飞出 + 粒子效果

---

## 7. 响应式适配

- 断点: Mobile (< 640px) / Tablet (640-1024px) / Desktop (> 1024px)
- Mobile 优先开发，Tablet/Desktop 渐进增强
- Mobile: 底部导航栏 (4 tab)，全屏学习页
- Desktop: 侧边栏导航，多列布局，可同时打开 AI 助手
- 所有触控目标在 Mobile 上 >= 44px
