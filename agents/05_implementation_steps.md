### 视觉风格锁定任务

在任何业务页面开发前，前端 Agent 和 Design Agent 必须先完成以下样例锁定工作：

| # | 任务 | 负责 | 产出 |
|---|------|------|------|
| 1.8 | 读取 `design_imgs/主页.png`、`附页1.png`、`附页2.png`、`附页3.png`、`ui组件设计参考.png` | Design Agent | 页面视觉拆解记录 |
| 1.9 | 建立样例图风格对应的页面路由和静态 mock 数据 | 前端 Agent | `/home`、`/explore`、`/learning`、`/profile` 可访问 |
| 1.10 | 建立基础布局组件：固定侧边栏、顶部栏、课程卡、统计卡、浮层卡 | 前端 Agent | 可复用 UI 组件 |
| 1.11 | Codex 对 `1440x900` 视口自主截图、保存日志、读取截图内容并自检迭代 | QA Agent + Codex | 截图、日志、自检记录、迭代清单 |

**执行顺序强制要求**:
1. 先实现静态风格基线页面，确保视觉风格贴合 `design_imgs`。
2. 再接入 API、状态管理和真实数据。
3. 若真实数据导致风格偏离样例图，应调整数据截断、容器约束、卡片样式或响应式规则，而不是改变样例图定义的视觉语言。
4. 样例图中的英文只作为布局和视觉密度参考，最终页面文案、按钮、卡片、弹窗、题目、解析和 AI 文案必须全部中文化。
5. 每轮视觉实现后，Codex 必须自主运行页面、截图、保存日志、查看截图内容、记录问题并迭代，直到风格自检通过。

### 验收标准

- [ ] `npm run dev` 启动前端，访问 http://localhost:3000 看到首页
- [ ] `uvicorn app.main:app` 启动后端，访问 /docs 看到 Swagger
- [ ] `docker-compose up` 一键启动所有服务
- [ ] CI 流水线通过 lint + test
- [ ] `1440x900` 下首页、探索页、学习页、个人中心页截图与 `design_imgs` 样式风格一致，且可见文案为简体中文，并有 Codex 自主截图、自检日志和迭代记录

## 5. Phase 4: AI 动态出题 Harness (D10-D12)

| # | 任务 | 说明 |
|---|------|------|
| 4.1 | AI Provider 封装 | OpenAI API 调用 + 错误重试 + Token 用量记录 |
| 4.2 | Prompt 模板系统 | 按年龄 + 学科 + 课程主题 + 难度 + 题型拼装 Prompt |
| 4.3 | CourseIntentAgent | 小模型/低成本模型理解用户课程选择，补齐结构化出题参数 |
| 4.4 | QuestionPlannerAgent | 规划题型、数量、难度分布和学习目标 |
| 4.5 | QuestionMemoryAgent | 检索生成题目知识库中的历史生成题、错题和用户偏好，提供去重上下文 |
| 4.6 | QuestionGeneratorAgent | 生成题目、选项、答案、解析 |
| 4.7 | QualityCheckAgent | 检查答案正确性、适龄性、难度匹配、重复度 |
| 4.8 | Tool Middleware | 统一封装生成题目知识库检索、保存、日志、质量检查结果写入 |
| 4.9 | 出题 API | POST /api/v1/questions/generate + batch 查询 |
| 4.10 | 错题变式 API | POST /api/v1/questions/:id/variant |
| 4.11 | AI 助手浮窗 UI | 右侧滑入 + 对话气泡 + 打字机效果；可触发出题/错题解析 |
| 4.12 | AI 速率限制 | Redis 滑动窗口限流，按出题次数和对话次数分别限制 |
| 4.13 | SafetyAuditAgent 实现 | AI Agent | 四维安全审查，独立否决权 |
| 4.14 | QualityReviewAgent 实现 | AI Agent | 抽样深度质量评估 + 趋势分析 |
| 4.15 | ErrorLogger 中间件实现 | Harness Agent | 错误捕获、四类分类、路由 |
| 4.16 | FeedbackAggregator 实现 | Harness Agent | PID计算 + 控制信号生成 + 状态观测 |
| 4.17 | SafetyAudit + FeedbackAggregator 集成测试 | QA Agent | 偏差信号回流验证 |

### 验收标准

- [ ] 用户选择课程参数后，可生成结构化题目、答案和解析
- [ ] 生成题目保存为批次，并沉淀到生成题目知识库，可在历史记录中查询
- [ ] 近期生成过的相似题目不会被重复生成
- [ ] 题目质量检查能标记答案缺失、难度不匹配、重复度过高等问题
- [ ] 答错后可生成同知识点变式题
- [ ] AI 回复和题目表述风格与当前年龄分级匹配
- [ ] 页面文案、AI 回复、题目、答案和解析均为自然简体中文
- [ ] 超速请求返回 429
- [ ] v0.1 不调用联网搜索 API

## 10. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| AI API 调用成本超预期 | 中 | 中 | 设置 Token 上限，缓存常用回答 |
| 年龄分级 UI 开发量超出预期 | 中 | 高 | 先实现 2 套主题（6-9 / 13-15），其余抽象后延 |
| 数据库 schema 设计不完善 | 低 | 高 | Phase 1 充分设计，Alembic 支持增量迁移 |
| 浏览器兼容性问题 | 低 | 中 | 使用标准 CSS，不支持 IE |
