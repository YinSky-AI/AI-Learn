## 1. 产品愿景

**让每个孩子都能拥有一个因材施教的 AI 老师。**

在传统教育中，个性化教学受限于师生比和教学资源。本平台利用 AI 技术，为 6-18 岁学习者提供自适应、自 paced、自选择的智能学习体验，打破"一刀切"的教学模式。

---

## 2. 用户画像

### 2.1 直接用户 — 学习者

| 画像 | 年龄段 | 特征 | 核心需求 |
|------|--------|------|---------|
| 启蒙探索者 | 6-9 岁 | 识字量有限，注意力时间短，喜欢图形和游戏 | 趣味性强、操作简单、即时反馈、大量视觉元素 |
| 知识构建者 | 10-12 岁 | 具备基础读写能力，开始形成逻辑思维 | 知识体系化、互动性强、有挑战性但不挫败 |
| 深度学习者 | 13-15 岁 | 抽象思维能力提升，面临升学压力 | 内容深度够、考点覆盖、错题分析、学习报告 |
| 自主规划者 | 16-18 岁 | 自主学习能力强，目标明确（高考/竞赛/兴趣） | 高难度内容、专项突破、模拟测试、知识图谱 |

### 2.2 间接用户 — 教学管理者（家长/老师）

| 画像 | 特征 | 核心需求 |
|------|------|---------|
| 家长 | 关注孩子学习效果和健康 | 学习报告、进度追踪、用时管控、内容安全 |
| 老师 | 关注教学辅助和数据 | 班级管理、学情分析、教学资源推荐 |

## 3. 核心价值主张

| 维度 | 价值 |
|------|------|
| 个性化 | 年龄分级 + 难度自适应 + 知识类型自由组合 |
| 智能化 | AI 动态出题、题目质量检查、生成题目知识库、错题解析、变式练习 |
| 游戏化 | 积分、成就、排行榜、学习激励体系 |
| 安全性 | 内容分级审核、隐私保护、适龄界面 |

## 4. 成功指标 (KPI)

### 4.1 产品指标

| 指标 | 目标值 | 测量方式 |
|------|--------|---------|
| 日活跃用户 (DAU) | v0.1 > 100 内部测试用户 | 埋点统计 |
| 单次学习时长 | 平均 > 15 分钟 | 会话追踪 |
| 内容完成率 | > 70% 的用户完成所选单元 | 进度追踪 |
| 难度切换率 | < 15% 的用户频繁切换难度 | 表示难度分级合理 |
| NPS (净推荐值) | > 40 | 内测问卷 |

### 4.2 技术指标

| 指标 | 目标值 |
|------|--------|
| 首屏加载时间 | < 2s (3G 网络 < 4s) |
| API 响应时间 (p95) | < 500ms |
| AI 推理首 token 延迟 | < 1.5s |
| 系统可用性 | > 99.5% |
| 用户数据隐私 | 符合《个人信息保护法》 |

## 5. 项目范围

### 5.1 In Scope (v0.1)

- 完整的年龄分级体系（4 级）与 UI 适配
- 三级难度切换（含自适应降级推荐）
- 学科（7 类）与学习形式（6 类）筛选
- 基础学习引擎：课程选择 + AI 动态出题 + 互动答题
- AI 出题 Harness：课程参数理解、出题计划、题目生成、题目质量检查
- 生成题目知识库：从用户使用过程中逐步沉淀历史生成题、答案、解析、质量检查、知识点标签和用户答题行为，用于去重、复习、错题变式和个性化练习
- 错题解析与错题变式生成
- 答案正误判断与即时反馈
- AI 助手：题目讲解 + 错题解析 + 练习辅助
- 用户注册登录与个人中心
- 学习进度追踪
- 激励体系（积分 + 成就徽章）
- Codex 自主视觉验收：按 `design_imgs` 截图、自检、保存日志并迭代
- 最终中文界面：样例图中的英文仅作为布局和视觉密度参考，实际页面文案、题目、按钮、提示和 AI 输出必须为简体中文

### 5.2 Out of Scope (v0.1, v0.2 规划)

- 联网搜索、搜索 API、网页抓取、第三方内容源接入
- 预置本地教材知识库或外部文档知识库建设
- 视频讲解与项目挑战形式
- 家长关联账号与班级管理
- AI 自由对话问答
- 学习报告自动生成
- 排行榜社交功能
- 真实材料题 / 新闻材料题 / 权威资料引用题（v0.2 可选）
