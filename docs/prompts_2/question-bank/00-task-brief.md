# 题库生成任务说明

## 这是什么任务

你是**题库内容生产的主导者**，需要为一个 AI 智能学习平台（FastAPI + PostgreSQL）产出一套完整的初始题库，涵盖 K-12 全学段。

**你的工作范围**：
- 生成/整理题目内容（通过你的知识和推理）
- 审核题目质量、适龄性、准确性
- 去重、补充解析
- 输出标准化的数据文件（JSON + SQL）
- 如有数据库连接信息，可直接执行 SQL 将数据写入项目数据库
- **所有产出文件必须保存到项目指定文件夹中**

**你不需要做的事**：
- 不需要修改项目业务代码
- 不需要实现新的系统功能
- 不需要搭建复杂的服务架构

## 项目数据库信息

```
数据库类型：PostgreSQL 16
数据库名：ai_learn
表名：questions（如不存在，你负责提供 CREATE TABLE 语句）
连接方式：通过 Docker Compose 运行的本地容器
  - 容器名：ai-learn-postgres
  - 端口：5432
  - 可通过 docker exec 进入容器执行 psql
```

如果任务发起方提供了具体的数据库连接字符串（如 `postgresql://user:pass@localhost:5432/ai_learn`），你可以直接连接并导入数据。如果没有，你生成 SQL 文件，由任务发起方自行执行。

## 你的最终交付物

所有文件必须存放在项目根目录的 **`sql/`** 文件夹中：

| 文件 | 路径 |
|------|------|
| 全量 JSON | `sql/questions_full.json` |
| 导入 SQL | `sql/questions_import.sql` |

**最终状态**：数据库 `ai_learn` 的 `questions` 表中存在 **至少 5460 道**题目，或提供了可直接导入的 SQL 文件。

## 数据格式

### 题目 JSON 格式

```json
{
  "subject": "math",
  "age_group": "13-15",
  "difficulty": "intermediate",
  "grade": "初三",
  "questions": [
    {
      "content": "已知关于 x 的一元二次方程 x² - 5x + m = 0 有两个相等的实数根，则 m 的值为（ ）",
      "options": [
        {"label": "A", "text": "m = 4"},
        {"label": "B", "text": "m = 6.25"},
        {"label": "C", "text": "m = -6.25"},
        {"label": "D", "text": "m = 2.5"}
      ],
      "correct_answer": "B",
      "explanation": "【知识点】一元二次方程有两个相等实数根的条件是判别式 Δ=0。\n【分析】判别式 Δ = b² - 4ac = (-5)² - 4×1×m = 25 - 4m。令 Δ=0，得 25 - 4m = 0，解得 m = 6.25。\n【常见错误】容易忽略 Δ=0 的条件直接选 D（m=2.5，即 b/2a），这是求对称轴的公式而非根的条件。",
      "type": "single_choice",
      "tags": ["一元二次方程", "判别式", "根与系数"]
    }
  ]
}
```

### 题型说明

| type 值 | 说明 | 选项格式 |
|---------|------|---------|
| single_choice | 单选题，4个选项 | `options: [{"label":"A","text":"..."}...]` |
| multiple_choice | 多选题，题干标注"（多选）" | 同上，correct_answer 如 "A,C" |
| fill_blank | 填空题，用 `____` 表示填空 | `options: null`，correct_answer 如 "6" 或 "3,5"（多空用逗号） |
| true_false | 判断题，固定选项 | `options: [{"label":"A","text":"正确"},{"label":"B","text":"错误"}]` |
| short_answer | 简答题，无选项 | `options: null`，correct_answer 给参考答案要点 |

### 干扰项设计策略（单选题）

错误选项必须具有干扰性，不能一眼排除：

- **计算错误**：给出常见计算错误结果（如进退位错误、正负号错误）
- **概念混淆**：用相近但不同的概念替换（如"因式分解"换成"化简"）
- **遗漏条件**：忽略题干中的关键限制条件
- **逆命题**：把正确结论倒过来说（如"A则B"→"B则A"）
- **扩大范围**：把特殊情况泛化为一般结论
