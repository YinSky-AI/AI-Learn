### 1.2 验收判定标准

每个验收项采用三级判定：

| 等级 | 标志 | 含义 |
|------|------|------|
| 通过 | PASS | 完全满足验收条件，无需修复 |
| 待修复 | FIX | 存在功能缺陷或体验问题，修复后重新验证 |
| 阻塞 | BLOCK | 核心流程不可用，必须修复后才能继续 |

## 3 用户认证验收

| 编号 | 验收项 | 验收条件 | 测试结果 |

| AC-AUTH-001 | 用户注册 | 填写用户名、昵称、邮箱、密码（6位+）、年龄、性别后提交，返回成功并自动登录跳转首页 | PASS |
| AC-AUTH-002 | 邮箱已存在提示 | 使用已注册邮箱注册时，显示"该邮箱已被注册" | PASS |
| AC-AUTH-003 | 密码校验 | 密码少于6位时提示"密码至少6位"；两次密码不一致时提示"两次输入的密码不一致" | PASS |
| AC-AUTH-004 | 邮箱/昵称登录 | 支持使用邮箱地址或昵称登录 | PASS |
| AC-AUTH-005 | 登录成功跳转 | 输入正确账密后跳转到首页，右上角显示用户昵称 | PASS |
| AC-AUTH-006 | 登录失败不刷新 | 输入错误密码后，页面不刷新不跳转，显示"用户名或密码错误"提示 | PASS |
| AC-AUTH-007 | 认证状态恢复 | 登录后刷新页面（整页导航），认证状态保持，用户昵称和统计正常显示 | PASS（第二轮验证通过） |
| AC-AUTH-008 | 登出清除数据 | 登出后清除 Token 和 localStorage 数据，跳转首页显示未登录状态 | PASS |

**关于 AC-AUTH-007**：第一轮测试中发现页面刷新后认证状态丢失。`AuthInitializer` 组件已在 `layout.tsx` 中配置，从 localStorage 恢复 Token 并调用 `fetchProfile()` 和 `fetchUserStats()`。第二轮浏览器测试确认：整页导航（`page.goto`）后认证状态正常保持，昵称和统计数据正确显示。

## 11 已修复问题清单（全部已验证）

| 编号 | 问题描述 | 影响 | 修复方案 | 验证状态 |
|------|----------|------|----------|----------|
| FIX-001 | 登录后页面刷新认证状态丢失 | 用户刷新页面后变回未登录 | `AuthInitializer` 组件增强：token 无效时清除，添加 isRestoring 状态 | 已验证 (v2) |
| FIX-002 | 登录失败时页面自动刷新跳转 | 无论正确或错误登录，页面都刷新回登录页 | `LoginResponse` 字段名改为 snake_case；401 处理跳过认证端点 | 已验证 |
| FIX-003 | 首页成就未登录时仍显示 | 未登录用户看到硬编码的成就数据 | 成就区域包裹在 `isAuthenticated` 条件渲染中 | 已验证 |
| FIX-004 | 首页统计数据为硬编码 | 统计数字不随用户实际学习数据变化 | 后端 `/users/me/stats` API；前端获取真实数据 | 已验证 |
| FIX-005 | 学习进度不反映课时完成 | 完成课时后首页进度不变 | 后端统计 `user_lessons` 表；前端完成课时后刷新 stats | 已验证 |
| FIX-006 | AI 对话非流式输出 | AI 回复等待完整响应后一次性显示 | 后端 SSE 流式；前端 `ReadableStream` 逐 chunk 更新 | 已验证 |
| FIX-007 | 登录仅匹配邮箱不支持昵称 | 后端只按 email 查询用户 | 登录查询改为 `or_(email, nickname)` 双匹配 | 已验证 |
| FIX-008 | apiClient 无法解析后端错误格式 | FastAPI 返回 `{"detail": {...}}` 但前端读取 `error.message` | 错误处理增加对 `detail.message` 的解析 | 已验证 |
| FIX-009 | 前端 API 参数名不匹配 | `pageSize`(驼峰) vs 后端 `page_size`(下划线) | `learning-store.ts` 全部改为 snake_case：`page_size`, `age_group`, `sort_by` | 已验证 (v2) |
| FIX-010 | 注册后自动登录字段名错误 | register 调用 login 时使用 `email` 而非 `username` | 改为 `username: (data.email \|\| data.username)` | 已验证 (v2) |
| FIX-011 | UserCourse 模型缺少 `last_accessed_at` | `/user/courses` 端点 500 错误 | 模型添加 `last_accessed_at` 字段；数据库 ALTER TABLE 添加列 | 已验证 (v2) |
| FIX-012 | asyncpg UUID 对象兼容性 | `_try_uuid()` 无法处理 asyncpg 返回的 UUID 对象 | `_try_uuid()` 增加 `hasattr(value, 'hex')` 检查，用 `str(value)` 转换 | 已验证 (v2) |
| FIX-013 | SQLAlchemy MissingGreenlet 错误 | `model_validate` 在 async session 外访问关系属性 | 路由层添加 `await db.refresh(obj, ["relation"])` 预加载 | 已验证 (v2) |
| FIX-014 | 课程卡片学科色块不显示 | Tailwind content 扫描路径不包含 `src/lib/` | `tailwind.config.ts` 的 content 添加 `src/lib/` 和 `src/stores/` | 已验证 (v2) |
