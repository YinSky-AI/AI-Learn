## 3. 全局样式问题与修复

### 3.1 Tailwind CSS 变量映射缺失 ❌ → ✅ 已修复

**问题**: `globals.css` 使用了 `text-foreground` 和 `bg-background`，但 `tailwind.config.ts` 中未定义这些颜色映射，导致编译报错。

**错误信息**:
```
Syntax error: The `text-foreground` class does not exist.
```

**修复措施**:

1. **tailwind.config.ts**: 添加 shadcn/ui 兼容的颜色映射
```ts
colors: {
  border: "hsl(var(--border))",
  input: "hsl(var(--input))",
  ring: "hsl(var(--ring))",
  background: "hsl(var(--background))",
  foreground: "hsl(var(--foreground))",
  primary: {
    DEFAULT: "hsl(var(--primary))",
    foreground: "hsl(var(--primary-foreground))",
  },
  // ... 其他映射
}
```

2. **globals.css**: 将 hex 颜色转换为 HSL 格式
```css
--background: 210 40% 98%;
--foreground: 222 47% 11%;
--primary: 221 83% 53%;
/* ... */
```

## 4. 未解决的问题

### 4.1 桌面端布局无法验证 ⚠️

**原因**: 浏览器面板视口限制在 702x582，小于 Tailwind lg 断点（1024px），因此始终显示移动端布局。

**影响**: 无法验证以下桌面端特性：
- 左侧固定导航栏（256px）
- 主内容区与侧边栏的间距（lg:pl-sidebar）
- 多列布局（4列课程卡网格、双列个人中心）
- 学习页右侧 AI 助手面板（328px 固定宽度）
- 1440x900 视口下的整体信息密度

**缓解措施**: 代码审查确认响应式设计逻辑正确（`hidden lg:block` / `lg:pl-sidebar` / `lg:grid-cols-3` 等），但无法通过截图验证实际渲染效果。

### 4.2 课程卡片学科色块未显示 ⚠️

**现象**: 探索页课程卡片顶部色块显示为灰色而非学科对应颜色。

**可能原因**: `getSubjectBgClass` 函数返回的类名可能未正确映射，或课程数据中的 subject 字段与映射不匹配。

**待排查**: 需要检查 `src/lib/utils.ts` 中 `getSubjectBgClass` 的实现。
